## Описание проделанной работы

### Задача

Реализовать переиспользуемый компонент ввода телефонного номера, который:
- поддерживает набор масок для разных стран;
- отображает номер в формате маски (незаполненные позиции — `*`);
- позволяет выбирать страну через выпадающий список;
- корректно обрабатывает ввод с клавиатуры и вставку из буфера;
- поддерживает состояния `default`, `success`, `error` и `disabled`.

### Архитектура компонента

```
PhoneInput/
├── PhoneInput.tsx          # Корневой компонент
├── store/
│   └── PhoneInputStore.ts  # MobX-стор: значение, маска, цифры
├── RegionSelector/         # Выбор страны (флаг + префикс)
├── MaskDigitField/         # Поле ввода по маске
├── DigitField/             # Одна цифровая ячейка
├── utils.ts                # Парсинг и форматирование масок
└── types.ts                # Типы и пропсы
```

Дополнительно вынесен хук `useListbox` (`src/hooks/useListbox.ts`) для доступной клавиатурной навигации в выпадающем списке стран.

### Основные возможности

**Маски и форматирование**
- Маска задаётся строкой, где `*` — позиция для цифры, остальные символы — статические разделители (например, `(***) ***-**-**`).
- Значение хранится в нормализованном виде: префикс страны + цифры и разделители маски, незаполненные позиции заменяются на `*`.
- При смене страны номер сбрасывается к шаблону новой маски.
- Автоматический выбор маски по префиксу номера (при совпадении префиксов выбирается более длинный, например `+375` вместо `+3`).

**Ввод цифр**
- Каждая цифра вводится в отдельное поле; при вводе фокус переходит к следующей ячейке.
- `Backspace` / `Delete` — удаление текущей цифры или переход к предыдущей ячейке.
- Стрелки `←` / `→` — перемещение между ячейками.
- Вставка (`Ctrl+V`) — заполнение нескольких ячеек подряд.

**Выбор региона**
- Выпадающий список с флагами стран (через Twemoji CDN) и телефонными префиксами.
- Анимация открытия/закрытия на Framer Motion.
- Клавиатурная навигация: `↑` / `↓`, `Home` / `End`, `Enter` / `Space`, `Escape`, закрытие по клику вне списка.

**Состояния компонента**
- `default` — обычное состояние;
- `success` / `error` — визуальная подсветка полей и текст статуса с иконкой;
- `disabled` — блокировка ввода и выбора региона.

### API компонента

```tsx
import { PhoneInput, PhoneInputStatus } from 'components/common/PhoneInput';

<PhoneInput
  masks={MASKS}           // массив масок стран
  initialValue={phone}    // начальное значение (опционально)
  onChange={setPhone}     // колбэк при изменении
  disabled={false}        // блокировка
  status={PhoneInputStatus.DEFAULT}
  statusText="Текст статуса"
  className="custom-class"
/>
```

Тип маски:

```ts
type PhoneMask = {
  key: string;    // ISO-код страны (для флага), например 'ru'
  name: string;   // название страны
  prefix: string; // телефонный префикс, например '+7'
  mask: string;   // шаблон, например '(***) ***-**-**'
};
```
